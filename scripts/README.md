# METAGENOMIC DATA PROCESSING PIPELINE

This repository contains Bash scripts for the processing of metagenomic data.  
Each script represents a step in the workflow and should be executed in the order  
indicated by its numeric prefix: `##_name.sh`.

**Note:** All scripts (except for step 2) require as input a text file containing a list  
of sample IDs. This file specifies which samples the script will process.

---

## WORKING DIRECTORY STRUCTURE

```bash
/data2/miel_dash/
├── data/
│   ├── SRR_ID/                  -> Text files containing lists of sample IDs
│   └── SRA_Mex/                 -> Data downloaded from SRA (Mexican samples)
└── results/
    ├── 01_fastqc_Mex/
    │   ├── zip/                 -> .zip files generated by FastQC
    │   ├── html/                -> .html reports generated by FastQC
    │   ├── trim/                -> .trim.fasta.gz files generated by Trimmomatic
    │   ├── metagenome_assembly/ -> .contigs.fa files generated by Megahit       
    │   │   ├── maxbin/          -> Bins generated by MaxBin
    │   │   └── checkm/          -> Bin quality evaluation using CheckM
    │   ├── taxonomy_reads/      -> Taxonomic classification of reads
    │   └── taxonomy_mags/       -> Taxonomic classification of MAGs
    ├── prueba_bioms/            -> Generated .biom files
    └── docs/                    -> Summary tables
```

---

## PROCESSING WORKFLOW

### STEP 1 - DATA DOWNLOAD  
Download of shotgun metagenomic samples from the SRA.  
**Output:** `.fastq.gz` files stored in `data/SRA_Es/`

```bash
./01_descargarSRR.sh /data2/miel_dash data/ids_SRR_txt/id_Es_1.txt SRA_Es
```

---

### STEP 2 - QUALITY CONTROL (FastQC)  
Generates `.zip` and `.html` reports for each sample.

```bash
./02_fastqc_mod.sh /data2/miel_dash SRA_Es 01_fastqc_Es
```

---

### STEP 3 - TRIMMING (Trimmomatic)  
Read filtering.  
**Output:** `.trim.fasta.gz` files

```bash
./03_trimmomatic.sh /data2/miel_dash SRA_E 01_fastqc_Es data/ids_SRR_txt/id_Es_1.txt
```

---

### STEP 4 - ASSEMBLY (MEGAHIT)  
Generates `.contigs.fa` files for each sample.

```bash
./04_assembly.sh /data2/miel_dash 01_fastqc_E data/ids_SRR_txt/id_Es_1.txt 
```

---

### STEP 5 - BINNING AND QUALITY EVALUATION

**5a - BINNING (MaxBin)**  
```bash
./05a_maxbin.sh /data2/miel_dash 01_fastqc_Es data/ids_SRR_txt/id_Es_1.txt 
```

**5b - QUALITY CHECK (CheckM)**  
```bash
./05b_checkm.sh /data2/miel_dash 01_fastqc_Es data/ids_SRR_txt/id_Es_1.txt 
```

---

### STEP 6 - TAXONOMIC CLASSIFICATION

**6a - READS**  
```bash
./06a_taxonomic_asignment_PFP.sh /data2/miel_dash 01_fastqc_Es \
data/ids_SRR_txt/id_Es_1.txt /data2/haydee/kraken_PFP 
```

**6b - MAGs**  
```bash
./06b_mags_read_mod.sh /data2/miel_dash 01_fastqc_Es \
data/ids_SRR_txt/id_Es_1.txt /data2/haydee/kraken_PFP 
```

---

### STEP 7 - BIOM FILE GENERATION  
```bash
./07_kraken_bioms.sh /data2/miel_dash 01_fastqc_Es muestras_Es
```

---

## UTILITY SCRIPTS

### `helper_checkmConcat.sh`  
Concatenates all `quality.tsv` files from step 5b.  
**Example:**
```bash
./helper_checkmConcat.sh /data2/miel_dash 01_fastqc_Es Es
```

### `helper_summaryConcat.sh`  
Generates quality summaries from FastQC `.zip` files.  
**Example:**
```bash
./helper_summaryConcat.sh /data2/miel_dash 01_fastqc_Es Es
```
